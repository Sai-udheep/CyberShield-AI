ABSTRACT  
Phishing attacks remain one of the most persistent and rapidly evolving threats in cybersecurity. As 
attackers continuously develop new techniques to deceive users, traditional detection methods such as 
blacklists and rule -based filters are no longer suffi cient. This research paper proposes an AI -driven 
phishing website detection system powered by advanced machine learning algorithms. The study utilizes 
lexical, host -based, and securityrelated URL features to classify websites as phishing or legitimate. 
Experimental analysis demonstrates that models such as LightGBM, XGBoost, and Random Forest 
significantly improve identification accuracy. The findings indicate that AI -based URL analysis can 
strengthen modern cybersecurity infrastructures.  
KEYWORDS : Phishing Detection, Machine Learning, Cybersecurity, URL Analys is, LightGBM, AI -
Based Security. 
1. INTRODUCTION  
With the exponential growth of internet usage, online activities such as banking, ecommerce, and social 
networking have become extremely common. However, this digital expansion has also led to an alarming 
rise in cybercrimes—particularly phishing attacks. Phishing websites mimic legitimate platforms to steal 
confidential information such as passwords, credit card details, and personal identities. The glo bal 
cybersecurity landscape has reported millions of phishing incidents annually, many of which bypass 
conventional security systems. Attackers often modify URL structures, embed hidden redirections, and 
use domain spoofing to avoid detection. Traditional systems like blacklists cannot keep up with these 
dynamic threats. Machine learning (ML) provides a powerful alternative by analyzing URL behavior 
patterns and automatically classifying harmful links. AI enables faster detection, higher accuracy, and

3.LITERATURE REVIEW  
Several studies highlight the importance of lexical and domain-based features for phishing URL detection. 
Early approaches depended on signature -based filtering, which quickly became ineffective as attackers 
generated new URLs at scale. Later studies introduced machine learning models that used URL length, IP 
presence, domain age, and token patterns to distinguish malicious websites. Recent research shows that 
gradient boosting algorithms—especially XGBoost and LightGBM— deliver high performance due to their 
tree-based structure and ability to handle complex feature interactions. Deep learning models such as CNN 
and RNN have also been explored, but their computational cost makes them less suitable for real -time 
deployment. A gap identified in previous research is the need for hybrid feature integration. Many models 
focus solely on lexical or host-based attributes. This study bridges that gap by combining multiple feature 
types to improve robustness against obfuscated URLs and short-lived phishing domains.  
 
4.METHODOLOGY  
The proposed AI -driven phishing website detection system follows a structured machine learning 
methodology. First, a labeled dataset consisting of phishing and legitimate URLs is collected from publicly 
available sources such as PhishTank, OpenPhish, and trusted domain lists. The dataset is then preprocessed 
through cleaning, removal of duplicates, handling of missing values, and normalization of numerical 
attributes. To address class imbalance, oversampling techniques such as SMOTE are applied.  
Next, feature engineering is performed to extract theoretical indicators of phishing behavior. These include 
URL-based features (length, structure, presence of suspicious symbols), domain -based features (domain

4.1 Dataset  
A dataset of 11,500 URLs was used for training and evaluation. It contains an equal distribution of 
phishing and legitimate URLs. All entries were preprocessed to remove duplicates, normalize text, and 
label data for supervised learning.

• URL entropy to detect randomness  
 
B. Security Features  
• HTTPS/SSL certificate details  
• Redirection count  
• URL shortening detection

5. RESULTS AND DISCUSSION  
The models were evaluated using accuracy, precision, recall, and F1-score. LightGBM achieved the highest 
accuracy of 99.81%, outperforming XGBoost (99.74%) and Random Forest (98.62%). LightGBM’s leaf-
wise tree growth and efficient handling of large feature sets allows it to process URLs quickly and correctly 
identify hidden malicious patterns. The model demonstrated strong resilience against:  
• Obfuscated URLs  
• Recently created malicious domains  
• Websites with multiple redirections  
This indicates its high suitability for real-time phishing detection applications.

• Accuracy: Proportion of correctly classified instances  
• Precision: Ability to correctly identify phishing sites  
• Recall: Ability to detect all actual phishing sites

7. FINDINGS 
1. Machine learning models demonstrated high accuracy in distinguishing phishing websites from legitimate 
ones using extracted URL, domain, and content-based features.  
2. URL structural features—such as abnormal length, use of special characters, and        deceptive patterns—
were found to be the most influential indicators of phishing activity.  
3. Ensemble learning techniques (Random Forest, XGBoost) achieved the best overall performance, 
providing strong generalization and low false-positive rates compared to individual classifiers.  
4. Data preprocessing and balancing using methods like SMOTE significantly improved model stability and 
reduced bias toward legitimate websites.  
5. Feature selection techniques enhanced model efficiency by reducing noise and retaining the  most 
discriminative attributes.  
 
8. CONCLUSION  
This research project successfully developed an AI-driven phishing detection system using Random Forest 
algorithm. The implementation demonstrated that Random Forest provides excellent performance in 
classifying URLs as legitimate or phishing, with accuracy rates exceeding 90%. The system's web -based 
interface provides accessible real-time protection against phishing threats. 
The project highlights the effectiveness of machine learning in cybersecurity  applications and provides a 
foundation for further development of intelligent phishing detection systems. By leveraging URL 
characteristics rather than relying solely on blacklists, the approach offers proactive protection against 
emerging phishing threats. 
The Random Forest algorithm was particularly suitable for this application due to its robustness, good 
performance with default parameters, and excellent feature interpretability. The implementation 
demonstrates that feature -based machine learning appro aches can significantly enhance cybersecurity 
measures while maintaining usability and accessibility for end-users. 
This research contributes to the growing body of work applying artificial intelligence to cybersecurity 
challenges and provides a practical implementation that balances accuracy, interpretability, and 
computational efficiency.
