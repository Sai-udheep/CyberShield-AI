1. Introduction  
Phishing attacks have emerged as one of the most widespread and harmful cyber hazards in today's 
ever-changing digital age. Phishing is a type of fraud in which scammers impersonate reputable websites 
to obtain sensitive user information such as login credentials, credit card information, and other personal 
information. According to the Anti-Phishing Working Group (APWG), phishing operations have lately

 Phishing attacks are increasingly complex and challenging to detect, posing 
a substantial challenge for cybersecurity professionals. This paper proposes 
a SHAP -based Interpretable Deep Learning Framework aimed at 
identifying phishing websites, emphasizing transparency in the m odels' 
decision-making processes. The five deep learning architectures evaluated 
were the Artificial Neural Network (ANN), Multi -Layer Perceptron 
(MLP), Autoencoder, Convolutional Neural Network (CNN), and

process employed several metrics, including accuracy, precision, recall, F1-

Explanations). The experimental resu lts demonstrate that the Bi -LSTM 
algorithm achieves superior performance, with an accuracy of 97.03%, a 
recall of 98.44%, and an F1 -score of 97.36%. SHAP visualization 
successfully identifies the most significant aspects in phishing classification, 
thereby enhancing both transparency and trust in the model. This method 
not only efficiently detects phishing but also provides clear explanations for 
individuals lacking technical knowledge. This study contributes to the 
development of a deep learning -based phis hing detection system that is 
both accurate and computationally understandable.

reached historic levels, with more than one million attacks documented in a single quarter of 2022 [1]. 
As the complexity and volume of phishing attacks increase, the need for accurate and reliable automated 
detection systems becomes increasingly urgent.  
Identifying phishing websites uses various techniques, such as list-based, visual similarity, heuristic, 
machine learning [2], [3], data mining [4], and deep learning, [5]. Various machine learning -based 
approaches have been developed to detect phishing sites, including Decision Tree, Random Forest, and 
Support Vector Machine. However, many of these models depend significantly on manually engineered 
features, which may not generalise effectively to new attack patterns or emerging phishing techniques 
[6]–[9]. 
Recently, deep learning has demonstrated remarkable capabilities in capturing non -linear patterns 
and automatically representing features from raw data [10], [11]. In phishing detection tasks, deep 
learning has shown improved accuracy and reduced dependency on manual feature extraction, making it 
suitable for identifying sophisticated or obfuscated phishing URLs [12]. Models such as Artificial Neural 
Network (ANN), Multi -Layer Perceptron (MLP), Autoencoder, Convolutional Neural Network 
(CNN), and Bidirectional Long Short-Term Memory (Bi-LSTM) have been successfully used in various 
fields, like detecting unusual patterns and enhancing cybersecurity [13]–[16]. However, despite having 
high performance, deep learning models are often criticised as black boxes due to their lack of 
interpretability [17], [18]. This lack of transparency poses a significant barrier in cybersecurity 
applications where explainability is crucial for analyst trust, auditing, and compliance [19]. 
To address this challenge, recent research has begun to adopt model interpretability techniques to 
provide a more profound understanding of the predictions generated by deep learning models. Some 
common strateg ies include SHapley Additive Explanations (SHAP), Local Interpretable Model -
Agnostic Explanations (LIME), and Grad -CAM. SHAP elucidates the contribution of each input 
feature to the model's choice, grounded in the Shapley value theory from cooperative game theory [20]–
[22]. In the context of web phishing detection, SHAP allows for the identification of important features, 
such as URL length, the presence of special symbols, or domain structure that significantly contribute 
to the classification as a phishing site. Interpretability techniques not only enhance user trust in 
automated detection systems but also provide valuable insights in designing more effective mitigation 
strategies against phishing attacks [23]–[25]. 
Few studies have integrated model interpretation techniques such as SHAP into a comp arative 
framework that evaluates multiple deep architectures, despite the expanding corpus of work on deep 
learning for phishing detection [7], [26], [27]. This study aims to provide an interpretable deep learning 
framework for phishing website detection by integrating SHAP explanations into the evaluation of 
several architectures. This work departs from previous research that primarily focuses on classification 
accuracy, instead emphasizing prediction performance and model transparency through SHAP -based 
analysis. Five deep learning architectures ANN, MLP, Autoencoder, CNN, and Bi-LSTM are rigorously 
evaluated based on classification metrics and explainability, offering insights into the influence of input 
data on model predictions. This dual focus on performance and interpretability addresses a critical 
deficiency in current literature and improves the reliability and usability of phishing detection systems.

2. Method 
This research aims to evaluate and compare the performance of five deep learning models in detecting 
phishing websites. The five models are Artificial Neural Network (ANN), Multi -Layer Perceptron 
(MLP), Autoencoder Neural Network, Convolutional Neural Network (CNN), and Bidirectional Long 
Short-Term Memory (Bi -LSTM). The research was conducted using a quantitative experimental 
approach, utilizing a processed dataset divided into training and testing data. Fig. 1 illustrates the stages 
of the research. 
 
Fig. 1. Research Stages 
2.1. Dataset 
The dataset that was utilized was obtained from the platform within the UCI Machine Learning 
Repository [28]. This dataset includes target labels in the form of binary values (0 stands for not phishing 
and 1 stands for phishing), as well as numeric features that indicate the qualities of URLs and web 
content. The data were normalized after the index column was removed to make the scales of the features 
more comparable to one another. The dataset was then stratified to ensure that the proportion of each 
class was maintained in a balanced manner, and it was separated into two parts: 75% for training data 
and 25% for validation data. 
2.2. Data Pre-Processing 
Normalization: Input features are normalized using z -score normalization , which is done by 
subtracting the mean and dividing it by the standard deviation [29], [30]. 
Data Reshape: The Bi-LSTM model transforms the data into a three-dimensional format (samples, 
timesteps, features), with timesteps set at 1, as the data is not sequential in time [31]. 
2.3. Model Architecture 
To ensure that the decision-making process is open and transparent, each model has been explicitly 
created and tuned to investigate  its potential for categorization against phishing data. Additionally,

3.1.3. Autoencoder Model Architecture 
The autoencoder model is used in this study as a representation learning-based approach to extract 
latent features from input data prior to classification. The architecture consists of two main components 
the autoencoder and the classifier, which are trained separately as show in Table 4. 
• Autoencoder Architecture 
An autoencoder is built with two parts: an encoder and a decoder. The encoder reduces the 
dimensionality of the original features to a lower -dimensional compressed representation (latent 
space), while the decoder reconstructs the original input from the latent representation. The 
encoder structure consists of two dense layers of 128 and 64 neurons, respectively, each using ReLU 
activation, followed by batch normalization. The latent representation layer consists of 32 neurons 
with ReLU activation. The decoder has a symmetric structure, with two dense layers of 64 and 128 
neurons, also using ReLU activation and batch normalization. The output layer uses a sigmoid 
activation function, with as many neurons as the input features, to reconstruct the input data. 
• Classifier Architecture 
The latent features generated from the encoder are then used as input to a separate classifier tasked 
with phishing classification. The classifier architecture consists of two hidden layers: 128 and 64 
neurons, each using ReLU, followed by batch normalization and dropout with a ratio of 0.3. The 
output layer consists of one neuron with sigmoid activation. The autoencoder is compiled using 
the mean squared error (MSE) loss function and optimized using the Adam optimizer, while the 
classifier uses binary crossentropy as the loss function. Both models are trained with early stopping 
to avoid overfitting.

3.1.4. Convolutional Neural Network (CNN) Model Architecture 
The Convolutional Neural Network (CNN) model in this study was built using a sequential approach 
and aimed to process tabular phishing feature data that had been reshaped into a 3-dimensional format 
so that it could be processed by a one-dimensional convolutional layer (Conv1D). The CNN architecture 
consists of two convolutional layers as show in Table 5. The first layer uses 64 filters with a kernel size 
of 3 and a ReLU activation function, followed by Batch Normalization and MaxPooling1D to reduce 
the feature dimensionality. The second layer uses 128 filters with a kernel size of 3,  also followed by 
Batch Normalization and MaxPooling1D. 
After passing through the convolutional layers, the data is flattened into a one -dimensional vector 
and then processed by a dense layer with 128 neurons and ReLU activation. To prevent overfitting, 
dropout was used with a dropout rate of 0.3. The output layer consists of a single neuron with a sigmoid 
activation function to generate a binary probability (phishing or non-phishing). The model was compiled 
using the binary crossentropy loss function and the Adam optimizer. The training process was carried 
out for a maximum of 100 epochs with a batch size of 512. Early stopping was used with a patience value 
of 10 and restore_best_weights was enabled. Model evaluation was carried out using accuracy, precision, 
recall, F1-score, and ROC-AUC metrics.

3.1.5. Bidirectional Long Short-Term Memory (Bi-LSTM) Model Architecture 
A Bidirectional Long Short-Term Memory (Bi-LSTM) model is built to capture temporal patterns 
and dependencies between features from phishing data that has been re-represented in the form of one-
dimensional sequences as show in Table 6. The input data is reshaped into a 3-dimensional form with a 
structure (samples, timesteps, features), where timesteps = 1. The Bi-LSTM architecture consists of two 
main bidirectional LSTM layers. The first layer uses 64 units with the configuration 
return_sequences=True to flow information to the next LSTM layer. The second layer uses 32 units and 
returns the final output of the sequence. After the sequential processing process, the output is continued 
to the dense layer twice: first with 128 neurons and ReLU activation, then with 64 neurons and ReLU 
activation. Each of these layers is followed by batch normalization and a dropout rate of 0.3 to reduce 
the risk of overfitting. The output layer consists of one neuron with a sigmoid activation function to 
produce a binary probability (phishing  or non -phishing). The model was compiled using binary 
crossentropy and the Adam optimizer. Training was performed for a maximum of 100 epochs with a 
batch size of 128 and using early stopping with a patience of 10.
